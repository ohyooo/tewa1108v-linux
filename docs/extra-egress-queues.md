# 扩展出口队列诊断

诊断范围从40队列扩为56队列，原有qid81..88与129..160不变，新增原厂port2对应qid161..168及port33对应qid169..176，保持现有EQM命令门控、错误隔离与部分结果valid语义

ethtool统计增加96项，合计1078项，ARMEL只读工具的静态缓冲及上限一起从1024扩为2048，不涉及用户态MMIO或模块卸载

候选网卡模块127392字节，低于131072字节加载上限，八模块及ARMEL helper已使用现有LLVM22.1.8编译通过

原厂OPP执行trace逐字确认port2的8词映射及port33的1024词映射，port33地址0x06058000 + priority*4 + selector*32，priority0..7、selector0..127，值BIT8 | (169+priority)

本轮仅扩大观测，未提交这些额外OPP映射，logical port2与33在实际CPU接收路径中的职责尚未确认，不能由编号或队列ID自行定义为CPU出口

已有IPS证据显示LAN1入口活动与PFE各级总活动同窗口增长，扩大队列采样用于判断未观察出口是否存在排队或计数增量，零离散快照仍不能证明从未通过
